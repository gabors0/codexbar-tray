What it shows

Everything you check the usage page for, already on screen.

Session & weekly limits

Both windows at once, with when each one resets. The tray icon draws them as two bars or rings, so you can read them without clicking.

Pace marker

A tick on each bar marks where usage should be at this point in the window. "13% in reserve" or "7% ahead of pace" tells you to keep going or slow down.

Local spend

Today, the last 30 days and a daily average, priced at API list rates from your ~/.claude and ~/.codex logs. Hover any day to see it.

Alerts that matter

Desktop notifications at 80% and 95% used by default (pick your own thresholds), and optionally when your session resets.

Many providers

Claude, Codex, Gemini, Copilot, Cursor, OpenRouter and the other providers the CodexBar CLI supports. Scroll the icon to cycle through them.

Stays in your home dir

No root, no system packages. Downloads are checked against their SHA-256, and updates are only offered, never installed without your OK.

Tray icon

Four ways to show it in your panel.

Drag the sliders. The colour turns amber at 80% and red at 95%, the same alert thresholds the app uses by default.

And a CLI

Script it, bind it to a hotkey.

~
# JSON snapshot for your status bar or scripts
$ limitray --status
# bind this one to a global shortcut
$ limitray --toggle
$ limitray --refresh
# update the app and the CodexBar CLI
$ limitray update --check
$ limitray update
$ limitray uninstall --purge

Installing

One command. Everything stays in ~/.local.

  1. 1

    Downloads the app

    The script fetches the latest limitray build for x86_64 or aarch64, verifies it, and copies it to ~/.local/bin.

  2. 2

    Fetches the CodexBar CLI

    A static CodexBar CLI goes into ~/.local/lib/codexbar-cli after a checksum check. If you already have one, it's reused.

  3. 3

    Adds it to your desktop

    Launcher entry, icon and login autostart, then the tray starts. Skip parts with --no-autostart or --no-start.

  4. 4

    Reuses your Claude login

    Sign in once with Claude Code (claude). The CLI reads the same credentials, so there's nothing to paste.

$ curl -fsSL https://raw.githubusercontent.com/gabors0/limitray/main/install.sh | sh

Coming from codexbar-tray? Run the same command. It stops the old app, carries your settings over and cleans up the old entries.

FAQ

Questions

Is this an official Anthropic, OpenAI or Google app?

No. Limitray is an independent, unofficial open-source project. It's built on the CodexBar CLI by Peter Steinberger, which does the provider fetching, and it's separate from CodexBar's own desktop app.

Does it need my API key or password?

No. For Claude, sign in once with Claude Code (claude) and the CodexBar CLI reads those same credentials. Nothing is pasted into Limitray.

How accurate is the spend number?

It's an estimate: token counts from your local ~/.claude and ~/.codex logs priced at API list rates. On a subscription plan it shows what that usage would have cost on the API, not what you're billed.

Which desktops work?

Anything with a StatusNotifierItem tray: KDE Plasma, GNOME with the AppIndicator extension, Sway or Hyprland with a waybar tray, and X11 desktops. It picks up your KDE colour scheme and font, or follows the system light/dark preference.

Does it update itself?

It checks GitHub once a day and offers updates for itself and the CodexBar CLI it installed. Nothing installs without your click. The previous version is kept as ~/.local/bin/limitray.bak. You can turn the check off under Settings → Advanced.

How do I remove it?

limitray uninstall removes the app, its launcher and autostart entries, and the CodexBar CLI if Limitray installed it. Add --purge to also remove settings and cache.
